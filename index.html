Why this usually shows blank: quote/checkout pages almost always send a security header (X-Frame-Options or a CSP frame-ancestors rule) that tells every browser "never display me inside someone else's page." That's enforced by the browser itself and set by Policybazaar's own server — no setting in this tool can override it, and it isn't a bug in the simulator.

To confirm: click Test Link ↗ above — if the page opens fine in its own tab but still won't preview here, that proves it's the frame-block, not a broken link.

Recommended: use Screenshot upload instead for questions based on this page — take a screenshot of the quote screen yourself and upload it. It scores identically and has zero dependency on network access or security headers.
